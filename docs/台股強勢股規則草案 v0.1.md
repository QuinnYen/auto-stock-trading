# 台股強勢股規則草案 v0.1

2026-10-08 · 自動短期股票交易專案 · 用途：交給 Claude Code 做回測驗證

## 先講結論

- 我查不到任何研究直接證明「強勢股做幾天到幾週的波段，扣掉成本後可以穩定賺」。多數證據是月到年尺度的投資組合研究，而且有的在扣掉交易成本後就不顯著。
- 學術上相對有支持的是「股價接近或創 52 週新高」這個條件，但仍有限制（見下表）。
- 停損幅度的研究結論互相矛盾，所以停損不能直接抄某個數字，要在回測裡當成參數掃描。
- 本草案裡的數字都是「回測起始假設與掃描範圍」，不是研究結論。每條規則都標了依據強度。

依據標籤：【研究】有台灣實證但有限制；【爭議】研究結論不一；【經驗】市場書籍或文章的說法，沒有實證；【推論】我自己的推論，需要回測驗證。

## 一、證據摘要

| 主題 | 查到的結果 | 限制與提醒 |
| --- | --- | --- |
| 52 週新高動能 | 台股 1995～2008 年資料中，持有 6 個月時只有 52 週高價策略的獲利顯著，月均報酬約 1.12%。另一篇 1998～2013 年的論文也發現持有 6 個月有顯著正報酬，但扣除交易成本後不顯著。 | 都是碩士論文，且持有期是 6 個月，不是你要的天到週。大盤大跌後反轉上漲的期間，這策略的獲利會明顯變差。 |
| 傳統價格動能（過去 3～12 個月漲幅） | 有研究（2008～2012）發現台股有動能效應；另一研究（2003～2020）發現沒有，但加上停損後出現顯著正報酬，7% 停損最好。 | 兩篇結論不同，期間與方法也不同。 |
| 停損幅度 | 1990～2016 年的研究：無停損沒有動能效果，10% 停損不顯著，15%、20% 才顯著。 | 與上一列的「7% 最好」互相矛盾，所以停損幅度必須自己掃描。 |
| 短期（一個月內）表現 | 有論文認為前期表現好的個股，短期適合用反向策略，中長期才適合動能策略。另有指數層級的研究支持台股一個月內有過度反應。 | 摘要看不出形成期細節。這對「追強勢股持有數天」是警訊，必須用回測確認。 |
| 均線與突破（指數層級） | 1981～2008 年台灣加權指數，均線與區間突破法則有預測力，扣交易成本後仍可獲利。 | 是大盤指數，不是個股。 |
| 均線與技術指標（個股層級） | 2007～2017 年隨機抽 145 檔，均線的淨值報酬沒有顯著優於買進持有，RSI 最好。2006～2016 年中型 100 成分股，均線篩選的投報率只略高於買進持有。 | 均線單獨用不可靠，比較適合當過濾條件。 |
| 技術分析何時有效 | 1990～2009 年研究：非法人成交比重越高、股價淨值比越高的公司，均線策略的效果越好。 | 暗示散戶比重高的股票技術訊號較有效，但也可能是流動性與風險較高的股票。 |
| 流動性 | 有文章指出多數因子在低流動性股票表現較好，但流動性本身也是風險，策略忽略它會高估績效。 | 部落格性質，只當提醒。 |
| 注意股、處置股 | 處置股改成分盤撮合，流動性大降。研究發現 2018～2021 年處置宣告後 3 日的超額報酬顯著為負。2026/08/10 起處置期間由 10 個營業日縮短為 5 個營業日。 | 新制才剛上路，歷史資料與新制不完全可比。 |
| 交易成本 | 一般股票賣出證交稅 0.3%，買賣手續費各 0.1425% 再乘折扣；一來一回約 0.35%～0.6%。 | 零股的最低手續費與折扣依券商而定，台新的條件還沒確認。 |

注意：以上都只讀到摘要，沒有讀到論文全文。重要的結論後面建議再找全文確認。

## 二、規則草案

### A. 股票池（先排除不能交易或不適合的）

1. 只做上市櫃普通股；排除 ETF、全額交割股。【推論】
2. 排除目前或近期被列為注意股、處置股的標的。注意股近幾日內的排除天數待掃描。【研究＋推論】
3. 排除當天漲停鎖死、實際買不到的標的。【推論】
4. 流動性：近 20 日平均成交金額須高於門檻，掃描 0.5 億、1 億、3 億。【推論，呼應流動性風險】
5. 價格上限：單檔預算 ÷ 股價 ≥ 10 股，才能比較精確控制部位。例如單檔預算約 6,700 元，股價上限約 670 元。【推論】

### B. 強勢定義（趨勢與相對強度）

1. 收盤價 > 20 日均線 > 60 日均線，且兩條均線斜率向上。【經驗】
2. 現價 ÷ 52 週最高價 ≥ 0.9，掃描 0.85～1.0。【研究，但持有期不同】
3. 近 N 日漲幅在全市場排名前 X%，N 掃描 20、60、120 日，X 掃描 10%、20%、30%。【爭議，短期可能反轉】
4. 近 N 日漲幅大於加權指數同期漲幅。【經驗】

### C. 進場規則（做成兩個版本互相比較）

版本 1：突破型

- 收盤創 N 日新高，N 掃描 20、60。【經驗】
- 當日成交量 ≥ 5 日均量的 k 倍，k 掃描 1.2～2。【經驗】

版本 2：回檔型

- 符合 B 的強勢條件下，股價回測 10 日或 20 日均線不破，並收紅。【經驗】

兩個版本共同的過熱過濾：

- 收盤價相對 20 日均線的乖離超過 Y% 不進場，Y 掃描 10%、15%、20%。【推論】
- 近幾日已連續大漲或漲停的不追。【推論】

大盤濾網：加權指數收盤低於 60 日均線時，不開新倉。【研究部分支持：大盤大跌後的反轉期，動能策略獲利會變差；其餘為推論】

### D. 出場規則（對績效影響可能比選股更大）

1. 初始停損：單筆 −X%，X 掃描 5%、7%、10%、15%。【爭議，研究互相矛盾】
2. 移動出場：收盤跌破 5 日或 10 日均線就出場。【經驗】
3. 停利：做兩種版本比較。
   - 版本 a：固定停利，目標是「淨賺約 100 元」，換算成股價約漲 1%～2%（依單檔資金而定）。
   - 版本 b：不設固定停利，只靠移動出場。
   - 你想要穩定小錢，所以版本 a 要認真比，但固定停利會截斷大賺的機會。【推論】
4. 時間停損：持有超過 M 個交易日還沒達到目標就出場，M 掃描 5、10、15。【推論】
5. 持股被列為注意股時，隔日開盤處理（出場或減碼），待回測決定。處置後流動性會變差，賣不掉的風險要納入模擬。【研究＋推論】

### E. 資金與帳戶風控

- 本金 2 萬元，同時持有 1～3 檔。
- 帳戶風控沿用既有設計：以收盤淨值的高水位計算，回撤 10% 就停止交易。
- 單筆最大虧損 = 單檔預算 × 停損幅度，回測時要列出來看是否合理。

## 三、回測規格（交給 Claude Code 時要寫清楚）

1. 資料：還原權息的日 K、成交金額、漲跌停價、注意股與處置股的歷史公告，且必須包含已下市的股票（避免存活者偏誤）。資料來源我還沒查，建議下一步先查。
2. 防止前視偏誤：訊號一律用 T 日收盤後的資料，成交最早假設在 T+1。零股盤中 09:10 才第一次撮合，之後每 5 秒撮合一次，買進價要用保守的假設。
3. 成本要全部扣：手續費（含折扣與最低手續費）、賣出證交稅 0.3%、滑價，以及漲停買不到、處置後賣不掉的情況。
4. 避免過度擬合：資料切成訓練期、驗證期、最後測試期，最後測試期只跑一次。參數掃描要找「周圍數值結果也穩定」的區域，不要挑單點最佳。
5. 對照組：
   - 同樣出場規則，但選股用隨機挑選，用來檢驗選股條件是否真有貢獻。
   - 買進持有 0050，只當底線，不當目標。
6. 評估指標：扣成本後的淨報酬、勝率、平均賺賠比、最大回撤、交易次數、逐月報酬分布、每筆淨賺達到 100 元的比例。
7. 建議的通過標準：扣成本後期望值為正；驗證期仍成立；參數小幅變動結果不崩壞；月度報酬不集中在少數幾個月。

## 四、還沒決定或還沒查的事

- 先做突破型、回檔型，還是兩個一起比？
- 「100 元」是固定停利目標，還是每筆淨賺的期望值？
- 歷史資料從哪裡抓、能否取得注意股與處置股的歷史名單？
