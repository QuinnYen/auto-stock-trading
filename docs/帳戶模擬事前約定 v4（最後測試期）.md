## 3. 範圍
- 僅 A-S2：規則 A「收盤創過去 250 個交易日新高、持有 60 個交易日」，最多 3 檔、每檔買當時淨值的 1/3、收盤跌破買進價 15% 隔天開盤賣、帳戶停機線 20%（停 20 個交易日後重啟）、單邊滑價 0.25%、手續費 3 折、賣出證交稅 0.3%、種子 1～20。**與驗證期完全相同，沒有任何參數改動。**
- 期間：2022-01-01 起至資料最後一個交易日（2026-10-07 前後）。
- 隨機進場對照：同期、同結構、種子 1～20。

## 4. 通過條件（與 v3 第 5 節相同的 6 條；只有期間長度的換算）
令 N ＝ 模擬的交易日數，年數 Y ＝ N ÷ 245。
1. 期末淨值中位數 ≥ 20,000 × 1.05^Y（年化約 5%）。
2. 20 次中至少 15 次期末淨值 > 20,000 元。
3. 期末淨值中位數**高於**隨機進場對照中位數。
4. 日曆年度（2022、2023、2024、2025、2026 的不完整年度）中，中位數路徑**至少 3 年**為正。
5. 最大回檔（中位數路徑）**不超過 40%**。
6. 去掉報酬最高的一年後，剩餘年度累計仍為正。

## 5. 結果的解讀與後續（事前定好）
- **通過**：代表 A-S2 在三段獨立期間（開發、驗證、最後測試）帳戶層級都滿足條件。這**仍不等於**會賺錢：之後還需要紙上交易（影子模式）確認實際成交價與滑價，才考慮台新 API 與實盤。
- **不通過**：此規則放棄；結論寫進規格，不換參數重試。
